# Violations de données personnelles (RGPD, articles 33 et 34)

Une **violation** est toute destruction, perte, altération, divulgation ou accès non autorisé à des données personnelles (compte piraté, sauvegarde perdue, e-mail envoyé au mauvais destinataire, clé USB égarée, accès d'un ancien bénévole non retiré…).

## Procédure

1. **Contenir** : suivre `docs/EXPLOITATION.md` §6 (maintenance, changement des mots de passe et secrets, restauration).
2. **Évaluer** : quelles données, combien de personnes, mineurs concernés ? Risque pour les personnes (usurpation, atteinte à la vie privée…) : faible / moyen / élevé.
3. **Consigner** dans le registre ci-dessous, même si la violation n'est pas notifiée.
4. **Notifier la CNIL sous 72 h** après en avoir pris connaissance, si la violation est susceptible d'engendrer un risque pour les personnes : <https://notifications.cnil.fr>.
5. **Informer les personnes** sans délai si le risque est élevé (modèle ci-dessous).
6. **Corriger et prévenir** : cause racine, mesure corrective, mise à jour de ce dossier.
